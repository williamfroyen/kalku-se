Integritetspolicy

Kalku värnar om din integritet. Webbplatsen är utformad för att kunna användas utan att Kalku aktivt samlar in personuppgifter om dig.

1. Personuppgifter

Kalku samlar inte in, lagrar eller analyserar personuppgifter såsom namn, e-postadress eller andra kontaktuppgifter via webbplatsen.

2. Cookies och spårning

Webbplatsen använder inga cookies, analysverktyg, annonseringsverktyg eller annan teknik för att spåra besökare.

3. Drift och tekniska uppgifter

Webbplatsen hostas via GitHub Pages. När du besöker webbplatsen kan GitHub behandla tekniska uppgifter, såsom din IP-adress, för att tillhandahålla och skydda tjänsten. Kalku använder inte dessa uppgifter för analys, profilering, marknadsföring eller spårning.

Mer information om GitHubs behandling av personuppgifter finns i GitHubs integritetspolicy: GitHub General Privacy Statement .

4. Tredje part

Kalku säljer inte personuppgifter och delar inte personuppgifter med tredje part för marknadsföring, annonsering eller analys. Tekniska uppgifter kan behandlas av GitHub i samband med drift och säkerhet för webbplatsen.

5. Dina rättigheter

Enligt GDPR har du, i den utsträckning personuppgifter om dig behandlas, bland annat rätt att begära information om behandlingen och i vissa fall begära tillgång, rättelse eller radering.

Du har även rätt att lämna klagomål till relevant tillsynsmyndighet, exempelvis Integritetsskyddsmyndigheten (IMY) i Sverige eller Datatilsynet i Norge.

7. Ändringar i integritetspolicyn

Vi kan komma att uppdatera denna integritetspolicy om webbplatsens funktioner eller behandling av personuppgifter förändras. Den senaste versionen finns alltid tillgänglig på denna sida.
